# Reference Match Studio v0.1.0

Reference Match Studio is a local look-development workspace for DaVinci Resolve users. It turns a calibrated source/reference still pair into a versioned `shotMatch` Profile and a reusable DCTL deployment.

## Highlights

- Professional Viewer workflow: Source, Reference, Result, Split and Difference.
- Waveform, RGB Parade, Vectorscope and match-delta checks.
- Human-readable `.rmatch.json` Profiles with a strict versioned schema.
- Reference Match Bridge generates the active `ReferenceMatchProfile.h` consumed by the stable `ReferenceMatch.dctl` engine.
- Local processing only: stills and Profiles are never uploaded by the application.

## Install

1. Clone or download this release.
2. Create a Python environment and install `requirements.txt`.
3. Run `python3 dctl_webui/server.py` and open `http://127.0.0.1:8766/`.
4. Save or import a Profile, then activate it.
5. Copy `dctl/ReferenceMatch.dctl` and `dctl/ReferenceMatchProfile.h` together into Resolve's LUT/DCTL directory and refresh its list.

## Compatibility

- Python 3.10 or later.
- DaVinci Resolve with DCTL support.
- Input contract: display-referred sRGB stills, or already-linear Rec.709 if selected explicitly.

## Important boundary

`shotMatch` preserves a calibrated mapping between a representative source condition and a reference. It is a starting point for a colorist, not a universal look that automatically adapts to all scenes.

# DCTL Generator PRD v0.1

**状态：** 初版草案，待需求评审
**产品形态：** 本地运行的 DCTL 参考图仿色生成工具
**当前入口：** `dctl_webui/`，默认地址 `http://127.0.0.1:8766`

## 1. 产品目标

为 DaVinci Resolve 调色流程提供一个本地辅助工具：用户导入一张参考图和一张代表性源静帧，在网页内检查参考图的色彩分布、调节全局迁移参数、预览结果，并导出可在 Resolve DCTL 节点中加载的静态 DCTL。

工具的定位是“生成可复核、可调整的初始 Look”，不替代调色师的镜头级曝光、肤色、选区和质感决策。

## 2. 用户与使用场景

| 用户 | 场景 | 期望结果 |
| --- | --- | --- |
| 调色师 | 为一组相近镜头建立参考风格起点 | 生成可直接放进 Resolve 节点的 DCTL，并可逐镜头微调。 |
| 影像创作者 | 用一张风格图快速探索画面方向 | 通过预览与示波器判断是否值得进入正式调色。 |
| 工程/算法维护者 | 复现某个 Look 的来源与参数 | 获取 DCTL、源/参考名称和参数 JSON。 |

## 3. 核心工作流

```text
选择参考图 + 选择源静帧
        ↓
查看参考图色板 / RGB 直方图 / Cb-Cr 矢量图
        ↓
确认输入编码，调节迁移量、色相/色度与保护
        ↓
生成与 DCTL 同链路的 PNG 预览，前后对比
        ↓
导出 DCTL + 参数 JSON
        ↓
在 Resolve 的 DCTL 节点加载，并逐镜头收敛
```

## 4. 功能需求

### 4.1 素材导入

- 支持参考图与源静帧的点击选择、拖放导入。
- 支持 JPG/JPEG、PNG、WebP、TIFF。
- 显示素材名称、尺寸和节点缩略图。
- 首版不支持视频直接解析、DPX、RAW 或多张图批量统计。

### 4.2 参考图分析

- 从参考图提取 10 色主色板，按感知亮度排列。
- 显示 RGB 三通道直方图。
- 显示 Cb/Cr 矢量示波器密度图。
- 显示亮度 P10 / P50 / P90。

### 4.3 DCTL 参数与预览

| 参数 | 范围 | 默认值 | 作用 |
| --- | ---: | ---: | --- |
| Input Encoding | sRGB JPEG/PNG、Linear Rec.709 | sRGB | 定义 DCTL 节点的输入约定。 |
| Mix | 0–1 | 0.75 | 整体迁移强度。 |
| Shadows / Midtones / Highlights | 0–1.5 | 1.0 | 三个亮度区间的迁移强度。 |
| Highlight Protect | 0–1 | 0.50 | 降低高光区域的迁移量。 |
| Warm Tone Protect | 0–1 | 0.25 | 降低暖色色域的迁移量。不是人脸检测。 |
| Hue Rotate | -30°–30° | +8° | 在 OKLab a/b 平面作全局色相校准。 |
| Chroma | 0–2 | 0.85 | 在 OKLab a/b 平面缩放色度。 |

- “生成预览”必须使用与导出 DCTL 一致的 OKLab、色相/色度和保护公式。
- 支持预览图与源静帧的可切换前后擦拭对比。
- 参数变更后，在已有预览的情况下自动更新预览；后续可评估是否改为手动触发以降低大图计算频率。

### 4.4 导出

- 导出一份 `.dctl`，且将当前网页参数写为 DCTL 控件的默认值。
- 生成同名 `.json`，至少记录：源图名称、参考图名称、输入编码、全部参数。
- 导出命名暂采用 `DCTL-Reference-Match-<随机标识>.dctl`。

## 5. 界面与交互要求

界面以 DaVinci Resolve 调色页的工作方式为视觉和信息架构参考，不复制其品牌元素或完整界面。

| 区域 | 责任 |
| --- | --- |
| 顶部项目/状态栏 | 展示当前工具、工作模式和本地服务状态。 |
| 左侧监看器 | 显示 DCTL 预览与前后比较。 |
| 中部节点流程 | 显示参考图、源静帧、DCTL 三个阶段；参考/源节点承担导入入口。 |
| 右侧检查器 | 集中显示输入编码、所有 DCTL 参数、预览与导出动作。 |
| 底部工具坞 | 固定展示参考色板、直方图和矢量示波器。 |

视觉原则：深灰工作台、低圆角、细分隔线、紧凑控件、浅灰为主文字；红色仅用于激活/节点提示，不使用消费级的大色块或卡片堆叠。

## 6. 算法与色彩契约

- 分析端将图片视为 display-referred sRGB / Rec.709 图像。
- 基础映射：在 OKLab 空间，对 L/a/b 三通道做源图均值与标准差到参考图均值与标准差的静态迁移。
- 后续依次应用 Hue Rotate、Chroma、暗中高光权重、高光保护与暖色保护。
- `sRGB JPEG / PNG`：DCTL 内部完成 sRGB 解码和编码。
- `Linear Rec.709`：只适用于上游 CST 已输出线性 Rec.709/sRGB 原色的节点。
- 导出的 DCTL 是静态 Look，不在 Resolve 内读取参考图或执行全帧统计；因此不会随帧闪烁。

## 7. 非目标与限制

- 不做语义分割、人脸识别、真实肤色检测或对象级保护。
- 不保证不同构图、光源或曝光的镜头与参考图逐像素匹配。
- 不作为 Resolve 插件、项目文件写入器或自动节点树编辑器。
- 不替代完整色彩管理、输入 CST、输出 CST 或显示校准。
- 首版不支持云端上传；所有图像处理在本机完成。

## 8. 验收标准

1. 空状态不显示破图图标、空图片 alt 文本或无意义占位内容。
2. 用户可从节点流程导入参考图和源静帧；导入后显示缩略图、名称及尺寸。
3. 导入参考图后，色板、RGB 直方图、Cb/Cr 矢量图和亮度分位可见。
4. 同一组图片和参数下，网页预览与导出 DCTL 的变换链路一致。
5. `Mix=0` 时导出 DCTL 在对应输入域内保持输入不变。
6. 生成预览、前后对比、DCTL 导出可完成，且浏览器控制台无相关报错。
7. 1440px 宽度下呈现“左监看—中节点—右检查器—底部工具坞”结构；窄屏不发生横向溢出。

## 9. 已实现基线

- 本地 Python 服务、图片上传、参考分析、预览、DCTL/JSON 导出。
- 当前 DCTL 的 OKLab 静态迁移和八项控制。
- Resolve 风格工作台布局与节点导入入口。
- 参考图分析和预览 A/B 对比。

## 10. 待确认的下一轮需求

以下不在本 PRD 中默认实现，等待确认后排期：

1. 是否升级基础算法为分位数亮度曲线 / 亮度分区色度映射，而非仅均值/标准差迁移？
2. 是否支持 DPX、DWG + DI、S-Log3 等工作空间？
3. 是否支持多张源图/参考图聚合，或按镜头组管理多个 Look？
4. 是否需要保存可重新编辑的本地项目（素材路径、参数、缩略图和版本）？
5. 是否需要导出 `.cube` LUT、PNG 预览或 Resolve 可导入的节点预设？
6. 是否需要为多镜头提供批量应用、适配建议或镜头差异提示？
7. 是否需要更严格的 DCTL 数学验证，例如回归测试、色卡测试和 Resolve A/B 输出比对？
